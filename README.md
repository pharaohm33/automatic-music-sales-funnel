# Automatic Music Sales Funnel

A step-by-step system for independent artists: turn a cheap influencer shoutout into a YouTube view, a YouTube view into a Beehiiv email signup, and that signup into a year of automated weekly emails that sell merch, shows, and giveaways — without manually pitching anyone.

**Live pages:**
- [Guide](https://pharaohm33.github.io/automatic-music-sales-funnel/) — the full system: the funnel diagram, influencer negotiation scripts and rate tiers, the welcome sequence, the 5-week rotating send calendar, and setup checklist.
- [Cheat Sheet](https://pharaohm33.github.io/automatic-music-sales-funnel/cheat-sheet.html) — a one-screen quick reference version of the same system.

Each page carries a QR code linking to the other, plus one linking to [MixedByEmmanuel.com](http://MixedByEmmanuel.com).

## What's in it

- **The mechanism** — how a single paid promo placement compounds into a permanently growing list, since every future video's description keeps feeding the same signup.
- **Influencer outreach** — vetting criteria, DM scripts (shoutout-for-shoutout, cold paid ask, volume negotiation), and a rate guide for negotiating ~4 story shares a week instead of a single post.
- **Beehiiv setup** — the welcome automation, the standing weekly rotation, real footer configuration (Settings → Design → Footer, not a link pasted per email), and list segmentation on paid plans.
- **The standing rule** — every new video gets added to the playlist and sent to the list, every time, either via an RSS-triggered automation or a manual drop into the rotation.
